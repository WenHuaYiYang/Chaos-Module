# 安装与升级

Chaos 由两部分组成：一个内核模块（`chaos_sup.ko`）和一个 Lua 安装器容器（`chaos-installer-p67.bin`）。
安装器负责把模块放进 `/data/chaos/`、写开机脚本，并与模块完成一次握手；之后每次开机由 `/data/rc.d/chaos.sh` 加载模块。

## 前置条件

| 项目 | 要求 |
|---|---|
| 设备 | 小米手环 10 Pro（`p67` / `M2551B1`） |
| 固件 | **3.101.043**（模块内是硬编码地址，其它版本不要装） |
| 安装工具 | AstroBox 等支持"自定义表盘 / 第三方应用"入口的工具 |
| 空间 | `/data` 余量 ≥ 1 MB |

> 刷机有风险。装之前先确认固件版本，并做好备份；固件升级后需要重新适配地址，旧模块可能直接加载失败或崩溃。

## 安装

1. 从 [Releases](https://github.com/WenHuaYiYang/Chaos-Module/releases) 或 CI artifact 下载 `chaos-installer-p67.bin`。
2. 用 AstroBox 的自定义表盘（或第三方应用）入口选择这个文件安装。
3. 安装器会逐拍执行：部署模块 → 写 `/data/rc.d/chaos.sh` → 与模块握手校验 → 恢复占位。
   状态行会显示当前步骤，失败会停在失败的那一步。
4. 安装完成后**重启手环**，让模块在开机时加载。
5. 打开 Chaos 应用。首次进入后按需打开"自动注入""后台恢复"等开关。

> 覆盖安装同样需要重启一次：安装器在模块已加载时只更新磁盘文件，重启后才会换上新模块
> （安装器不做 `rmmod`，原因见 [卸载与回退](#卸载与回退)）。

## 升级

1. 下载新版本安装器，用同样的方式安装。
2. 重启手环。
3. 打开 设置 → 关于，确认版本号是最新的 `v1.0.x`。

升级**不会**清掉你的配置：`/data/chaos/` 下的设置、排除名单、字体与日志都保留。

## 验证安装成功

| 检查项 | 期望 |
|---|---|
| 桌面出现 Chaos 图标 | 是 |
| 设置 → 关于 的版本号 | 与发布的版本一致 |
| 设置 → 运行日志 | 有"模块加载: /dev/chaos 注册成功"一类记录 |
| 应用管理页能读到应用列表 | 是（读不到说明模块没加载或固件不匹配） |

如果图标出现但打开就退回桌面，通常是模块没加载（检查 `/data/chaos/sup.ko` 是否完整、`/data/rc.d/chaos.sh` 是否存在）。

## 卸载与回退

**当前不提供一键卸载**，这是有意的：

- 安装器从不 `rmmod`。模块加载时把页面回调注册进了固件的 launcher 链，`rmmod` 会释放模块内存，
  但链上的条目还指向那块内存；之后切表盘、翻桌面时 launcher 遍历到悬空回调就会崩。
- 因此"卸载"只能靠**换回一个干净的固件 / 恢复出厂**，或者装一个功能等价的空模块。

回退到旧版本：直接安装旧版安装器并重启即可（配置保留）。

## 常见问题

**装完重启后手表反复重启？**
说明模块在开机时加载失败或崩溃。拔掉/还原 `/data/rc.d/chaos.sh`（或恢复出厂）即可恢复。常见原因：
固件版本不对、`sup.ko` 传输中断导致文件不完整、`/data` 空间不足。

**图标在，但应用管理列表是空的？**
模块没加载成功。看 设置 → 运行日志；没有日志文件说明模块根本没起来。

**换了字体但界面没变？**
字体要先通过字体投递包安装到 `/data/chaos/font/`，再在 设置 → 系统美化 → 字体 里切换；切换后需要让界面重绘（退出重进或息屏唤醒）。

**升级后桌面图标消失？**
覆盖安装后必须重启一次。仍不出现就重装一次安装器。
