# 灵动点功能球

主线目标为小米手环10 Pro（p67）、固件3.101.043。RW6独立移植线未接入。

## 使用

入口为“主页 → 设置 → 灵动点”，与应用图标一样使用原生第三级列表。
首次安装默认关闭；启用后默认在右上角，以48 px半透明平面圆点显示。

- 圆点大小：32、40、48、56、64、72 px六档。
- 半透明：球体使用纯色底、清晰的粗环与电池图标，去掉高光、渐变、立体边缘和阴影，保留真正的alpha；圆球之外完全透明，关闭半透明后球体为实色。弧带为圆角半透明黑底，无描边，选项之间是两端留空的灰色圆头短隔条。
- 三个快捷位置：同一条连续弧形扇带分为三段，默认依次为时间、常亮、亮度，可选择时间、亮度、截屏、常亮、回到表盘、震动开关、自动亮度、录屏开关和屏幕翻转共九项。同一个功能不能重复占位，选择已使用的功能会交换两个位置。
- 位置：长按圆点后拖动，松手吸附到最近屏幕边的最近点，保留沿边位置；菜单随位置选择朝向并向屏幕内侧展开。
- 电量进度：球内粗环始终首尾闭合相连，覆盖完整360°，浅色和灰色直接衔接；满电时浅色绕满一圈。随着电量减少，带空心小圆点的端头沿圆周收缩，剩余部分显示为灰色轨道。小圆点位于移动端，中央电池图标保持固定；未知电量只显示灰色整圈，不伪造端点。启用后可在设置中查看读数。
- 轻点展开或收起；点击菜单外的空白处收起。拖动松手不会误触展开。

时间以HH:MM直接显示在主弧带上，不必进入另一个页面。所有弧带文字逐字按曲线切线转向，四个角分别排布，字形不会被镜像。
常亮进入同样造型的二级弧带，提供5min、10min、15min；选择后开始计时并返回主菜单，启用的功能用灰色小圆点标记。再次选择当前时长可提前结束；更换时长会从新选择的时刻重新计时，重启不恢复。
亮度二级界面为连续的白色弧形滑条，从当前值沿弧相对滑动调整，按下任意位置都不会跳值，并在弧上显示nit数值；原地长按后慢滑可逐nit微调。持续滑动不会自动切入微调。触摸输入合并为最多每32ms一次硬件更新，松手后及时提交最后的数值。界面没有额外的加减按钮或居中面板。数值文字会根据下方白色填充切换深浅，以保持可读。范围为1～2000 nit，手动调整会退出自动亮度。
在二级菜单轻点圆点返回主弧带，点击空白收起，不切换当前前台应用。

启用后圆点挂在固件显示顶层，在桌面、原生应用和快应用间保持可用。
息屏/AOD时隐藏，唤醒后恢复。关闭功能会移除自有图层。
系统自己新建的顶层对话框仍按系统原来的层级显示。

## 常亮与截屏

常亮沿用项目已使用的p67屏幕超时服务：记住原超时，临时设置最大支持值，并在亮屏时定期续期。
倒计时结束、手动结束常亮、关闭灵动点或主动息屏会恢复原值；期间在系统设置中更改的超时优先保留。
不写入用户的系统持久设置，也不会在用户主动息屏后反复唤醒。

截屏选择后先隐藏整个灵动点图层至少150ms，再由现有后台截图任务保存当前画面的BMP。
保存目录沿用“截屏设置”的选择，完成后恢复圆点并显示结果。成功、失败和启动失败提示均在2秒后自动收起，无需点击。
不会覆盖或取消原来已经等待息屏的截图任务；已有任务时提示启动失败。
如果在开始截图前息屏，本次请求取消，不会在之后某次亮屏时补截。

## 更多快捷功能

三个位置均可自由选择以下快捷项，沿用已有模块和原生服务：

| 快捷项 | 行为 |
| --- | --- |
| 回到表盘 | 系统主页面板复位＋应用级归主页请求，持续确认直到表盘在最前台；已经在表盘时不重复请求，超时、用户新导航或息屏会结束等待 |
| 震动开关 | 切换系统震动门控，提示当前状态；本次运行有效，重启后跟随系统设置 |
| 自动亮度 | 开关原生自动亮度；手动拖动亮度仍会退出自动模式 |
| 录屏开关 | 开始录屏，再次触发停止并保存；格式与目录沿用录屏设置 |
| 屏幕翻转 | 通过已有显示旋转模块切换180°方向，触摸映射随之调整 |

## 电量读取

直接调用3.101.043原生`power_manager`电量读取入口`0x0CA6E6A9`，与系统UI读取同一个电量缓存（`0x2013EF10 + 0xB0`）。检查结果在0～100范围内，每5秒同步一次；手势或展开/吸附动画期间推迟同步。不打开设备节点、不发送跨核电量请求，读取失败或缓存尚未就绪时保留“电量暂不可用”的明确状态。

上一版使用通用设备节点探测，遗漏了固件实际使用的`/dev/charge/`目录，导致真机显示不可用。本版移除这条探测路径，以已核对的系统电量函数为唯一来源。固件身份、调用点和实际ARM代码验证见[FLOATING-BALL-SERVICES-ABI.md](FLOATING-BALL-SERVICES-ABI.md)。

## 实现与性能

| 文件 | 职责 |
| --- | --- |
| `supervisor/src/floating_ball.rs` | UI-owner状态、动作队列、持久化、常亮租用和截图协调 |
| `supervisor/src/floating_ball/model.rs` | DOT2/兼容DOT1配置、贴边投影、随位置变化的弧带几何、手势和缓动 |
| `supervisor/src/floating_ball/pixels.rs` | 平面球体/完整粗环、移动圆点端头、4倍采样圆角遮罩及半透明黑色弧带 |
| `supervisor/src/floating_ball/curved.rs` | 字形切线旋转、双线性抗锯齿和原生I8索引透明文字层 |
| `tools/build_floating_ball_assets.py` | 球体编译、圆角/分隔条遮罩及OFL字形图集生成 |
| `supervisor/src/fw_api/battery.rs` | 系统电量缓存读取与范围校验 |
| `supervisor/src/fw_api/navigation.rs` | 原生主页复位与应用级归主页请求 |
| `supervisor/src/fw_api/floating_ball.rs` | 已有顶层图层、图像、按钮、事件和定时器接口 |
| `supervisor/src/page/floating_ball.rs` | 页58～60的原生设置、大小和功能单选 |

展开/收起约180ms，吸附约200ms，使用三次缓出。动画期间目标节拍16ms，空闲回到1000ms。
主菜单与两个二级界面共用一条弧带，文字交叉淡入淡出。只创建一棵自有控件树，常规展开/收起动画仅调整位置与透明度。亮度拖动按最新输入合并更新预分配的弧带纹理，不反复重建控件。
动画回调不读写配置、不格式化时间、不读 framebuffer。时间按秒获取，仅在显示文本变化时更新标签。
球体像素与描述符64字节对齐，使用与S541相同的预乘格式和GPU cache-clean流程；球体两份像素共32 KiB，弧带双缓冲共128 KiB，圆角/分隔遮罩缓存共32 KiB，三组I8文字双缓冲共102 KiB；仅在GPU空闲后复用非当前缓冲，并先退役旧图像缓存。以上像素/遮罩缓冲共294 KiB，不含小型描述符及固件缓存。弧形字形使用OFL许可图集，CJK 20px / ASCII 16px，角度计算和采样均为定点整数；未增加未验证的固件旋转入口。

配置位于`/data/chaos/floating-ball.cfg`，DOT2固定16字节，保存边和沿边比例；校验和、字段范围与功能去重检查保持有效。兼容旧DOT1配置，保留原开关、大小、透明设置、三个功能和原角位置，下次保存时写为DOT2。
写入临时文件、回读核对，再rename替换；拖动过程中不写闪存，仅在落点改变时保存。
事件回调不删除图层，创建和清理在维护UI定时器执行。图层被系统删除后，通过当前顶层的子表确认存活再重建。

## 验证

```bash
python3 tools/test_floating_ball.py
python3 tools/test_capture.py
python3 tools/verify_floating_ball_services.py /path/to/vela_ap.bin
# 可选原始固件机器码探针，需要Unicorn与pyelftools
python3 tools/probe_floating_ball_services.py /path/to/vela_ap.bin
python3 tools/build.py --firmware 10p-3.101.043
```

主机回归使用真实功能球控制器和原生图层适配代码，替换底层VFS/显示接口；新增圆角、无描边、短隔条不连边、逐字转向、白底深色字及四角字形不镜像检查；覆盖四边全部大小和沿边位置的弧带命中与可见范围、最近边投影、旧配置迁移、平面实色/无高光阴影、始终首尾相连的完整粗环、随收缩端移动的小圆点、固定图标/alpha与更新缓存、提示自动消失/时钟回绕、新快捷项分派、亮度按下不跳值和更新合并、亮度连续拖动、5/10/15分钟到期与时钟回绕、GPU忙时延迟发布、透明像素、长按抑制、常亮恢复、配置短读写和失败保存、截图隐藏时序、图层删除与重新创建。
截图回归覆盖新增的亮屏立即截图、忙任务拒绝及息屏取消，并继续验证GIF/APNG/BMP的实际解码。

主机回归包含42项功能球测试与42项截图测试；完整ARM构建使用项目统一入口。精确原厂固件探针另需自备AP，覆盖电量0～100与异常值、回主页请求顺序、无效接口拒绝和四个主页面板复位；图形驱动和应用分派为明确替身。主机测试与ARM完整构建不能代替真机验收。尚需在对应固件确认系统电量缓存更新、原生归主页后的表盘状态、震动开关覆盖范围、触摸锁定、系统模态覆盖、透明混合、截图时图层确实已经从最终显示缓冲消失、常亮对各类系统息屏路径的作用，以及实际动画帧率和耗电。
16ms是调度目标，不代表已经测得真机60 fps或任何场景绝不卡顿。

## 素材再生成

正常构建使用已入库素材，Pillow即可运行 `python3 tools/build_floating_ball_assets.py` 重新生成。安装了NumPy时会自动加速圆角遮罩生成。留档参考PNG、平面底色/图标BGRA、整圈粗环遮罩、OFL字体子集及许可证位于 `supervisor/assets/floating-ball/`，生成物摘要记录在 `ASSETS.json`。
