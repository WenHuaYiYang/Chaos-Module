# 2026-11-16 性能优化首批交付

> 历史记录（2026-11-16）：保留当时基线与阶段结果；当前行为、取舍和验证边界见 [性能说明](PERFORMANCE.md)，记录目录见 [历史索引](history/README.md)。

目标：小米手环 10 Pro / p67，固件 **3.101.043**。源码版本保持 1.2.4，
这是本地性能优化构建，非上游正式发布。安装器同时包含此前的应用管理启动回归修复。

## 已实施

- 模糊 V2：合并 BGR888 与 RGB565 的 4×4 降采样遍历，保留两种输出各自的舍入方式。
- 模糊和控制中心按钮：按批预计算颜色 LUT，逐像素不再重复计算对比度、亮度和染色。
  LUT 占用约 1.5KiB 静态空间，避免把大表放在原生 UI 线程栈上。
- 首页：数值刷新使用单调时钟；不再仅因每秒统计而持续要求全局 50ms 维护。
  离开 Chaos 或息屏时不刷新主页统计。
- 开机隐藏补偿：等待重试不再保持全局快拍，采用 2/4/10 秒退避，五分钟墙钟上限。
- 隐藏看门狗：改为亮屏 800ms、息屏 160s 的墙钟巡检，避免其他动画提高其扫描频率。
  静默兜底重放使用独立时钟；请求迁移仍在定时器入口处理。
- 字体热替换：息屏不再推进无可见收益的扫描，亮屏扫描路径保持原行为。
- 应用详情：先展示页面，目录大小按每拍最多 24 个遍历步骤、2ms 软预算统计；
  支持离页/息屏关闭目录句柄、返回后重算。单次原生 VFS 调用自身仍可能超过预算。
- 修复开启动画误接管 Chaos 内部启动、随后因不在桌面而丢弃请求的问题。
- 修复 MinGit 无 cygpath 时响应文件路径转换，并补齐 Windows/Clang 23 测试兼容。

没有降低模糊分辨率、调整颜色参数或削减动画帧率；截图/GPU fence/缓存同步仍保留。
缓冲池、GPU 放大、按钮共享 atlas 裁剪、字体增量扫描和全局任务预算仍属于后续计划，
未将这些未实施项计入收益。

## 测试

以下检查通过：

- `tools/test_performance.py`：ASan/UBSan 像素等价、颜色 LUT 与原公式对照、
  合并采样与原 RGB565 结果对照、stride/padding、缓存失效、文本缓存、时钟回绕。
- `tools/test_detail_scan.py`：生产目录扫描逻辑的嵌套/缺失目录、每拍步数上限、
  精确大小、取消/恢复和目录句柄关闭。
- `tools/test_corona_blur.py`：模糊生命周期/发布/重试、四区域 owner、恢复、
  通知图标和配置测试。通知图标宿主 fixture 将 const 路径改为 static，
  避免 Windows 多代码生成单元复制常量而破坏模拟 VFS 的地址身份；生产 owner 未改。
- `tools/test_blur_v2.py`、`tools/test_cc_buttons.py`、`tools/test_blur_params.py`。
- `tools/test_build.py`：11 项；`tools/test_firmware_symbols.py`：15 项。
- 完整 ARM 构建与 ELF 校验：目标身份、零未定义符号、允许的重定位类型。

Windows 主机 Release 微基准的一次最终运行（相同输入、每项 120 轮）：

| 本次改动 | 原路径 | 新路径 | 局部加速 |
|---|---:|---:|---:|
| 颜色调整 | 27ms | 12ms | 2.25× |
| 两种降采样输出 | 22ms | 13ms | 1.69× |

主机计时受调度、编译器和计时精度影响；其他运行颜色约 1.52×、采样约 2×。
这不是整机帧率、功耗或手环端耗时的测量。已有 separable 插值相对旧标量公式的
加速没有算作本次新收益。

没有连接手环，也没有提供精确固件镜像；真实 GPU/缓存、触摸手感、耗电、
原生引擎和完整 ARM 固件探针尚未验证。新增快应用回归探针已加入源码但未执行。

## 构建环境与复现

在工作区 `.tools` 中准备 Python 3.12.10、Rust nightly 2026-11-15
（x86_64-pc-windows-gnullvm / rustc 1.102.0-nightly）、rust-src、
thumbv8m.main-none-eabi、LLVM-MinGW 20261104、Node 22.16.0，以及项目 Python 依赖。
系统已有的 Git 便携 shell 可满足构建；未要求重启系统或全局修改 PATH。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
. ..\.tools\env.ps1
python tools/build.py --firmware 10p-3.101.043
```

工作区环境脚本使用本机绝对路径。换机器请按 BUILD.md 安装同类工具，
或修改环境路径；源码不依赖这些本机路径。产物 SHA-256 和资源清单由
`dist/10p-3.101.043/build-report.json` 记录，交付目录另附校验清单。
