# 蜂窝应用列表

小米手环 10 Pro（p67）/ **3.101.043** 的可选原生蜂窝应用列表自 v1.1.7 引入。复用系统图标、应用顺序和启动回调，支持双向拖动、惯性、独立间距调节、整体缩放、边界返回及原生编辑/删除。

v1.1.9 整理独立调距、编辑归位、进场准备、开关持久化和即时应用。本次提交仅包含源码及文档，未构建或更新 `dist/`，仓库既有二进制不代表本次版本。

完整模拟器的进场首帧、删除转场与帧率仍待复测；以下主机及固件指令验证不等同于显示验收。

## 使用

1. 安装 `dist/chaos-installer-p67.bin` 后重启，替换 RAM 中的旧模块。
2. 将系统应用列表设为网格视图。支持原生模式 1、2；单列列表与编辑状态交由系统处理。
3. 打开 Chaos → 系统美化 → 应用列表设置 → **蜂窝视图**。开关名称无括号文字，底部独立文字只说明操作，不占用列表项。
4. 中间区域上下左右拖动图标云；松手后惯性滑动。轻点启动应用；在惯性中轻点只停止滑动，下一次轻点才能启动。
5. 左侧边缘 28 像素内按下，纵向起滑后，上滑缩小图标间距、下滑放大间距，范围为默认间距的 87.5%–200%。此操作独立于整体缩放，中心图标大小保持不变，边缘图标仍按位置缩小。横向起滑仍拖动图标云；轻点和原地长按保留原有操作。
6. 右侧边缘 28 像素内按下，上滑放大、下滑缩小。图标和已调节的间距同步变化，范围 50%–150%。左右边缘调节均由触摸起点捕获，移出边缘后保持当前操作，松手后无调节惯性。
7. 到顶部后继续下拉、到左端后继续右滑，向外超过 24 像素后交还系统返回。惯性、缩放和间距调节不会触发退出；左缘横向右滑仍可返回。
8. 原地长按应用进入系统编辑，再按原生流程删除可卸载应用。拖动、缩放或调距后的长按不会误入编辑；退出编辑后恢复蜂窝。

开启蜂窝会关闭 RW6 缩放、排距、内缩三项；开启任一 RW6 项会关闭蜂窝。两种模式在设置页切换时均重新绑定并立即应用，无需滑动列表或重启。关闭蜂窝恢复原生布局，不自动重开 RW6。系统样式按钮在蜂窝中隐藏，更换样式前先关闭蜂窝。

最多显示 128 个应用；超过上限保持原生列表，不截断清单。所有缩放及间距档位均允许把每个图标拖到中心。间距与缩放不写入配置，容器重建或退出原生编辑后恢复默认。

## 设置和生命周期

蜂窝开关持久保存到 `/data/chaos/honeycomb.cfg`：`HCB1` 加单字节 0/1，重启后恢复上次选择；缺失、短文件、错误标记或非法值默认关闭。RW6 仍保存到 `applist.cfg`；启动时若两份配置都开启，以蜂窝为准并清除 RW6 三项。设置页切换时立即保存并应用；跨文件保存先关闭原模式，再保存新模式，写入失败由维护定时器重试。网格尚未就绪时保留选择，待容器可用后接管。

立即应用先交还旧对象的布局和事件，再写入所选参数并重新绑定。蜂窝重用已注册的布局 ID，重新安装当前对象的类、布局与事件；RW6 写表后重设原生布局并调用原生重排、坐标提交和重绘，无需等待滚动。原生转场或快照暂时占用时保留刷新请求，空闲后只补一次；布局回调内的重应用请求只登记，不做对象修改或 I/O。

只修改模块及当前容器的 RAM 类、布局、事件和几何状态，不改写固件分区或复制应用注册表。应用删除通过系统编辑与确认流程完成。

每次重排均重新遍历当前子表，不跨定时器保存图标句柄。接管前先通过父容器子表核验网格，再核验原生类指纹；关闭时恢复类、布局、原始事件过滤器和所属 flags。派生析构作废模块状态，原生析构由 LVGL 基类链执行一次。

## 布局与转场

| 模块 | 职责 |
|---|---|
| `supervisor/src/honeycomb_layout.rs` | 整数六边形环、边缘图标缩放、两轴相机、独立间距、缩放、惯性、位移边界和手势仲裁 |
| `supervisor/src/honeycomb.rs` | RW6 互斥、设置保存、输入、原生容器生命周期和按需重排 |
| `supervisor/src/fw_api/honeycomb.rs` | 精确固件 ABI、类/布局接管、事件绑定、原生坐标提交和快照协作 |
| `supervisor/corona_blur.c` | 在 Chaos 适配层协调 Corona 的位置回调；上游实现保持原样 |

原生布局从 `icon+0x18` 的 `{x,y,w,h}` 读取坐标，通用 `obj_align` 会被覆盖。蜂窝为当前网格注册独立布局，更新这些矩形并调用 `0x0C514655` 提交绘制及命中坐标。保留原生应用回调身份和 app_id，拖动仲裁通过额外的 `SHORT_CLICKED` 回调完成。

布局回调只进行有界矩形计算和提交，不设置缩放/显隐/样式，不挂接事件、删除动画、重绘、写文件或恢复对象。固件即使对已可见图标重复清除 HIDDEN，也会重新置脏父布局；禁止在布局回调内执行这类操作，避免布局循环无法结束。几何不匹配时仅登记故障，由 UI 定时器关闭并恢复。

进场前准备图标，沿最多 12 层祖先链定位系统或 Corona 的位置回调。网格尚未填充或选定样式时也先安装监听，维护阶段修复系统重新绑定的回调；开始、结束和位置变化通知均可在同一事件中接管刚就绪的网格，补准备不等待下一次维护，也不在事件里读写配置。生成快照前先完成蜂窝布局，清理所属页面上的旧快照并跳过普通网格重置，随后由原生捕获函数生成蜂窝位图。暂时无法清理的快照保留并稍后重试，不直接关闭蜂窝。原生结束事件仍负责清理快照、显示实时视图及清除滚动标记；事后观察器只在几何变化时补齐更新。

长按在同一次输入事件中先交还类、布局和点击回调，再调用原生编辑事件，跳过中间刷新及维护定时器的第二次重排。不跨定时器保存事件对象或图标指针，删除确认与可卸载条件由系统处理。

退出原生编辑后，对同一存活网格执行 240 ms 的缓出归位，位置和图标大小一起过渡。起点读取当时可见的对象坐标和图像缩放，避免误用原生元数据中已写好的最终位置；捕获后仅停止一次原生图标动画，再由蜂窝帧定时器推进。布局回调使用同一插值结果，不抢先提交终点。归位状态最多保存 128 份几何数据，约 2 KiB，不保存图标指针或位图；列表变化、容器重建、关闭或离屏会结束过渡。移动期间阻止点击和长按，恢复后需重新按下，避免误启动。

动画使用独立 UI 定时器，移动目标周期 16 ms，静止或离屏时周期为 1000 ms；通用维护仍为 50 ms。缓存位移边界，图标集合未变时不逐帧挂接事件，也不逐帧扫描全局动画表。**16 ms 是调度目标，实际帧率尚未测量。**

## 验证

```sh
# 20 项布局/手势测试 + 76 个独立控制器场景
python3 tools/test_honeycomb.py
# 包含 Corona 位置回调与蜂窝协作，使用 ASan/UBSan
CC=cc python3 tools/test_corona_blur.py
# 以下验证需要自行提供精确固件 AP，不在仓库分发
python3 tools/verify_honeycomb_abi.py /path/to/vela_ap.bin
# 另需 unicorn、pyelftools 和 Rust ARM 工具链
python3 tools/probe_honeycomb_abi.py /path/to/vela_ap.bin
python3 tools/probe_honeycomb_geometry.py /path/to/vela_ap.bin
python3 tools/build.py
```

主机回归直接编译生产 Rust 布局、控制器和 RW6 设置模块；固件调用使用模型。覆盖左右边缘调节独立性、方向锁定、轻点与长按、组合极限下全部应用可达、中心应用锚定、边界返回、编辑交接顺序、归位首帧和连续插值、延迟/回绕计时、归位中误触与生命周期变化、首次维护前/离屏/网格未就绪后的准备、结束和位置通知补准备、重建与监听修复、快照冲突重试、重复重绘抑制、布局阶段禁用变更 API、故障恢复与互斥。

持久化和立即应用回归覆盖开机恢复、双配置冲突优先级、无维护间隔的立即接管、同一对象重复绑定、对象重建、关闭和 RW6 切换的保存顺序、布局阶段延后及网格未就绪后补应用。RW6 ARM 探针核验写表先于原生重排、布局重新绑定、实际坐标提交、转场后重试和静止不重复刷新；原生重排的像素计算仍使用模型。

固件指令探针核验 AP、原生类、调用点、搬运表和 thunk，执行实际输入读取、布局循环、坐标提交、滚动选择器、位置回调及应用删除条件。探针复现重复清 HIDDEN 引发的布局循环，并验证纯几何回调一轮返回；核验快照在蜂窝坐标准备后捕获、结束事件仍清除标记，且只删除所属页面的快照。提前监听探针覆盖 12 层祖先、接管前识别、回调重挂后修复、不重复添加及关闭恢复；无关或超深容器仍被拒绝。

编辑归位探针核验原生 200 ms 模式动画及逐图标写入回调，执行生产 ARM 几何捕获，验证读取当前可见坐标而非元数据终点，整数尺寸往返不丢像素，并确认不依赖位置动画标记的一次性取消与后续帧无重复取消。

位图像素生成、显示、部分尺寸/样式依赖、动画删除、编辑界面、注册表和应用管理服务仍使用模型；验证未实际删除应用。完整模拟器仍需检查进场首帧、左缘调距、右缘缩放、四向拖动、边界返回、删除确认与过渡、编辑恢复、实际帧率、应用清单变化和开关恢复。
