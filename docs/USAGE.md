# 使用说明

Chaos 打开后是主页（信息页），四个一级入口：**应用管理 / 表盘 / 系统美化 / 设置**。
所有页面都是原生 LVGL 页面，没有网页或脚本解释器参与。

## 主页

- 两个圆环分别显示**存储占用**与**内存占用**，中间是百分比。
- 圆环只读，触摸拖动已被关闭（避免误改显示）。
- 末行"关于"进入关于页；该页的版本号行**连点 5 次**可进入隐藏调试页（见 [调试入口](#调试入口)）。

## 应用管理

隐藏/显示应用、批量操作、排除项，以及"普通 / 深度隐藏"两种存储模式。
两种模式的固件依据、代价与验证清单单独成篇：[APP-MANAGER.md](APP-MANAGER.md)。

要点：

- 单点条目切换隐藏状态；一键隐藏/显示作用于整个列表，排除项会被跳过。
- 排除项管理（页 7）里的勾选项不参与批量操作，也不在页 1 显示。
- 普通模式（默认）不重启即可显隐，代价是开机瞬间可能闪一下图标；深度模式开机即不注册，但显示需要重启。
- 切换模式本身需要重启一次才完全生效。

## 表盘

- **表盘切换**：在已安装（内置 + 市场）表盘之间切换。
- **摇一摇轮换**：编辑参与轮换的表盘清单，摇动手腕切下一个。
- **表盘管理**：查看表盘清单与占用，切换/删除单个表盘。

## 系统美化

- **更换字体**：列出已投递的字体（`/data/chaos/font/` 下的槽位），点选即切换；删除需要两步确认。
  字体本身由独立的字体投递包安装，安装器容器里只带一个占位文件。
- **桌面图标**：应用图标包——选择一套图标包应用，或恢复系统原图标。
  图标包由 `installer/icon_pack.lua` 投递（`CIPK` 容器）。
- **系统模糊**：开/关系统模糊；**模糊区域**选择哪些区域参与模糊。
- **表盘通透背景**：生成并复用静态背景；固定图片模式需要 `background.bin`。

## 设置

时间设置、日期设置、亮度、震动、缓存清理、运行日志、版本信息。
时间/日期直接写 RTC，滚轮交互与系统闹钟页一致。

## 运行日志

关键操作（应用显隐、批量、模式切换、字体/图标切换、异常）带时间戳写入 `/data/chaos/chaos.log`，
单文件上限 48 KB，超限自动滚动。日志页分页显示，可清空（两步确认）。

## 调试入口

关于页的**版本号行连点 5 次**，页面标题变为"调试"，可用的调试项：

- LVGL 对象内存 dump 导出（512 KB）
- 圆环字段对比矩阵（四环：默认角度 / 整圆背景 × 25% / 75%）
- 圆环构造参数记录

调试页只在当次进入有效，回主页即清调试态。普通用户不需要用到它。

## 数据目录

| 路径 | 内容 |
|---|---|
| `/data/chaos/sup.ko` | 模块本体（安装器部署） |
| `/data/chaos/chaos_icon.bin`、`chaos_icon_settings.bin` | 桌面图标 |
| `/data/chaos/settings.cfg` | 用户设置 |
| `/data/chaos/appmgr_excl.bin`、`appmgr_keep.bin`、`appmgr_apply.cfg` | 应用管理名单与配置 |
| `/data/chaos/font/` | 字体槽位与 `index.txt` 清单 |
| `/data/chaos/chaos.log` | 运行日志 |
| `/data/chaos/shake.cfg`、`shake-wfaces.cfg` | 摇一摇轮换配置 |
| `/data/rc.d/chaos.sh` | 开机加载脚本 |
