# 陀螺仪触控点

适用主线：小米手环 10 Pro（p67），固件 **3.101.043**。

## 使用

在 **Chaos → 设置 → 显示与交互 → 触控点** 进入三级设置列表，打开其中的“启用触控点”。
默认关闭，开关会保存，重启后恢复。中心点直径 **20px**、绿色进度环直径 **48px**、线宽 4px；
中心点带深色描边，便于在浅色界面辨认。黄色中心点表示正在等待数据或恢复准备，
白色中心点表示可以操作。转动手腕移动触控点，悬浮层覆盖表盘、Chaos 和其它原生页面。

切换页面后，触控点回到屏幕中央，清除旧页面的点击倒计时和按压，**按“切页暂停时间”等待后恢复**。
暂停时间为 **0～10 秒整数，默认 2 秒**；设为 0 秒时不额外等待，但仍会清除旧点击状态。
暂停期间不移动触控点、不累计点击进度，也不学习转腕动作为零偏；手腕不必静止，
持续转动也不会延长等待。再次切页会重新开始所设暂停时间，恢复后重新计算完整的点击确认时间。
首次开启及息屏/传感器中断后的准备，同样不再无限等待静止：连续有效数据下最多 2 秒，
可用的静止样本只用于可选零偏校准（约半秒可提前完成）。数据异常或断流时仍暂停虚拟输入。

- 在同一点附近停稳至设定的“点击确认时间”，外围绿色圆环逐渐填满，随后模拟一次轻触；默认 **900ms**。
- “点击位移灵敏度”设置倒计时允许的位移半径，范围 **1～30px**、默认 **6px**。数值越大，允许的抖动越多；位移超出范围立即重置倒计时。判定依据是相对计时起点的累计位移，不是相邻两帧的位移。
- 一次点击后，需移动至少 **14px** 才能在附近重新点击；位移容差大于14px时须移出该容差范围。静止不动不会连续点击。
- 触控点外圈碰到屏幕边缘时，**立即朝该边缘滑动**，不要求停止转腕、不等待点击确认时间，也不显示点击倒计时：

| 接触位置 | 模拟的手指动作 |
|---|---|
| 上沿 | 向上滑动 |
| 下沿 | 向下滑动 |
| 左沿 | 向左滑动 |
| 右沿 | 向右滑动 |

滑动从屏幕内侧开始，持续约 300ms，行程为相应方向屏幕长度的一半。
停在同一边缘可重复滑动，每次释放后间隔 700ms；离开再碰到边缘立即触发下一次滑动。
边缘滑动不受“点击确认时间”或“点击位移灵敏度”影响。绿色倒计时只用于中心区域的点击确认。
具体表现由当前页面决定，例如列表滚动、分页或返回。四角优先选择距离最近的边，
距离相同时优先上下方向。

实体触摸会打断虚拟操作并重置倒计时。息屏时隐藏悬浮层、关闭陀螺仪订阅并释放
虚拟按压；恢复亮屏后进行上述有时间上限的准备。开启状态下的输入定时器在息屏时降为 1 秒，
因此亮屏后触控点恢复可能有约 1 秒延迟；它不会主动亮屏或更改自动熄屏时间。
关闭开关后，下一次输入回调立即禁止继续触发，维护定时器随后删除虚拟输入设备和悬浮层。

三级列表包含：

| 项目 | 范围与默认值 |
|---|---|
| 启用触控点 | 默认关闭；旧版本的启用状态保留 |
| 移动灵敏度 | 25%～300%，默认 100%；数值越大移动越快 |
| 点击确认时间 | 300～5000 毫秒，默认 900；仅用于点击 |
| 点击位移灵敏度 | 1～30 像素，默认 6；数值越大，对手腕抖动越宽松 |
| 切页暂停时间 | 0～10 秒整数，默认 2；0 表示无额外等待，仅影响切页后的暂停 |

点击数值项进入纯数字输入，保存后立即生效并持久保存。超出范围保留输入页提示修改；
写盘失败显示“保存失败”，原有参数保留。参数更改会取消进行中的倒计时/按压并重新准备，
不会用旧进度立刻触发操作。左右移动方向已按反馈反转，竖直方向保持原样。
屏幕翻转 180° 时同步反转移动方向并转换输入坐标。模拟器安全模式 `SIM_LITE` 不启用此功能。

## 实现

- `supervisor/src/gyro_pointer/logic.rs`：独立于固件的运动滤波、有上限的零偏准备、可调切页暂停、停留计时、
  四边滑动轨迹、冷却和点击重新启用逻辑。水平使用 `gyro.y`，竖直使用 `gyro.x`，
  增益为 420px/rad × 灵敏度百分比；运动轴的佩戴方向与实际手感仍需设备调校。
- `supervisor/src/gyro_pointer/config.rs`：参数范围、数字解析、GTP1/GTP2/GTP3 兼容和 GTP4 校验。
- `supervisor/src/page/gyro_pointer.rs`：三级设置页（页 61）与纯数字参数输入。
- `supervisor/src/gyro_pointer.rs`：开关持久化、UI 线程生命周期、传感器数据读取和状态显示。
- 切页识别复用已核对的原生页管理器，比较描述符、app/page ID 与当前根对象身份，
  不缓存后再解引用页面对象。表盘和 launcher 共用 16:0，额外比较现有表盘可见标志；
  同一页面内的普通列表滚动不会触发切页暂停。快应用内部自行管理、未更换原生页身份的路由仍需逐页实测。
- `supervisor/src/fw_api/gyro_pointer.rs`：固件接口、20 字节虚拟输入数据和全局绘制。
- `supervisor/src/watchface.rs`：现有全局维护定时器负责创建和退役；即使 Chaos 不在前台仍工作。
- 输入来自独立的 LVGL pointer 设备，原物理驱动、read callback、driver data 均由系统继续持有。
  注入完整的按下、移动、释放序列，让 LVGL 派发控件点击、手势与滚动。
- 触控点位于 `layer_sys`，高于普通页面和 `layer_top`。透明容器、圆心与圆环均清除
  CLICKABLE/SCROLLABLE/SCROLL_CHAIN，不参与页面命中；圆环 INDICATOR 为绿色，隐藏 KNOB。
- 配置为 `/data/chaos/gyro-pointer.cfg`：14 字节 `GTP4`，包含启用字节、u16 移动灵敏度、
  u16 确认毫秒数、u16 位移容差像素数、u16 切页暂停秒数（均为小端）与 XOR 校验。
  读取旧 5 字节 GTP1 时保留启用状态；读取10字节 GTP2 时保留启用状态、移动灵敏度和确认时间，
  补默认6px容差；读取12字节 GTP3 额外保留位移容差。旧格式均补默认2秒切页暂停，下一次保存写为 GTP4。
  先完整写入同目录临时文件，回读校验后 rename；
  数值保存失败保留原参数，本次关闭仍优先执行。

每 20ms 最多读取八个传感器事件。事件积压时只排空数据，清除按压与停留状态，
不使用积压轨迹完成点击。超过 160ms 没有递增时间戳，或出现非有限值、异常角速度、
屏幕旋转、实体触摸时，先 reset 虚拟输入再释放，避免将取消当成普通点击。
连续 2 秒没有新数据或读取错误会关闭订阅，并按 2 秒间隔重试。

## 固件证据

本轮核对的 AP SHA-256 为：
`519307675665e4866d722a8119a98589c397b614ac3294cb87bfc86de45756ec`。
固件镜像存放在研究工作目录，不加入源码或安装包。

| 接口/结构 | .043 固件证据（文件偏移） |
|---|---|
| 陀螺仪节点 | `0xAAD47C`：`/dev/uorb/sensor_gyro0`；只读 + NuttX `O_NONBLOCK=0x40` |
| 事件大小 | `0xC32EFC` 的 sensor_gyro 元数据，esize 为 **24** 字节；timestamp u64，x/y/z/temperature f32 |
| 采样间隔 | `0x229838` 的原生 orb_set_interval 把整数微秒转发给 ioctl `0xA81`；当前请求 20000us |
| 创建输入 | `0xA00C90` thunk → 搬运后的 `0x1C050649`，源 `0x9DA88` |
| 删除输入 | `0x1C0506D5`，源 `0x9DB14`；系统触摸驱动清理路径的函数指针位于 `0xA6560` |
| 枚举输入 | `0x4C7F20` thunk → `0x1C050741`，源 `0x9DB80` |
| 设置类型/回调 | `0x1C050799` / `0x1C0507B1`，源 `0x9DBD8` / `0x9DBF0` |
| 取消按压 | `0x4C7DC8` thunk → `0x1C05084D`，源 `0x9DC8C` |
| 系统悬浮层 | `0x4C8DC8` thunk → `0x1C02FB75`，源 `0x7CFB4`，读 display+0x2CC |
| indev 布局 | 大小 204；read_cb +4，state +0x0C，display +0x24，read_timer +0x28 |
| 输入数据布局 | `0x9E938` 清零 20 字节，`0x9E964` 传给 read_cb；state +18，continue_reading +19 |
| 当前页身份 | `0x9ACF4C` 读页管理器 `0x2013EDE4`，`0x9ACF5E` 调 `0x9AA7CC` 取描述符，`0x9ACF64` 读根 +0x30；复用 sys.rs 的 app/page 字段 |
| 表盘/launcher 区分 | `0x3FF564` 加载可见标志地址 `0x2010C980`，`0x3FF568` 读该字节；复用现有 `watchface_is_on()` |

搬运关系取自 AP 的启动复制表 `0xB20`，没有把文件副本加 flash 基址当成可调用地址。
公开实现对照：[openvela LVGL 输入结构](https://github.com/open-vela/apps_graphics_lvgl/blob/dev/src/indev/lv_indev_private.h)、
[输入处理](https://github.com/open-vela/apps_graphics_lvgl/blob/dev/src/indev/lv_indev.c)、
[NuttX uORB 类型](https://github.com/open-vela/nuttx/blob/dev/include/nuttx/uorb.h)、
[NuttX 文件标志](https://github.com/open-vela/nuttx/blob/dev/include/fcntl.h)。
公开分支会变化；此实现以指定 AP 的实际布局为准，不能直接使用新头文件中带 status 的 gyro 大小。

## 验证与边界

```sh
python3 tools/test_gyro_pointer.py
python3 tools/verify_gyro_pointer_abi.py /path/to/vela_ap.bin
python3 tools/probe_gyro_pointer_abi.py /path/to/vela_ap.bin
python3 tools/build.py --firmware 10p-3.101.043
```

主机测试执行生产控制器与生命周期代码，覆盖修正后的左右方向、放大后的可达边缘、
切页回中/取消旧输入、默认2秒及自定义0/1/3/5/7/10秒恢复、暂停时间持久化和GTP3迁移、
连续切页和时钟回绕、旧点击锁定解除、
恢复后的完整点击倒计时、暂停期间手指优先/过期数据拒绝、传感器中断后有上限的恢复、
四边首次接触立即同向滑动、重复间隔/离开再触碰、位移容差对点击的实际影响、
移动灵敏度比例、300～5000ms 确认时间、GTP1/GTP2旧配置迁移、校验损坏、数值范围及保存失败、
运动/容差、进度、单次点击、重新移动、
四边滑动及重复、实体触摸、断流/异常数据/积压、时间回绕、180° 翻转、配置短写及失败、
息屏恢复、关闭期间的取消与延迟退役。固件核验脚本绑定 AP 摘要、搬运关系与真实指令。
ARM 探针使用原生创建/设置/取消/删除及读取指令，分配、定时器、事件和控件派发边界为明确替身。

以上不代表真机验收。仍需在 p67 / 3.101.043 上检查：正常/翻转方向、实际佩戴轴、
圆点与绿色环显示、表盘/设置/应用列表/快应用中的命中、边缘滑动、手指接管、
息屏恢复、反复开关，以及启用时的功耗。部分固件页面可能使用设备专属的输入预处理；
其滑动/导航行为必须逐页实测。当前不模拟长按、多指或旋转手势。
