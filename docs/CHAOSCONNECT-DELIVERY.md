# ChaosConnect 投递包安装

配套 Android 0.6.0 在“功能列表”最上方提供“安装投递包”，通过系统文件选择器读取 Chaos 制作台导出的 `.bin`。支持 `/chaos-bandpack-web` 的字体投递包和 CIPK 图标投递包（包括可选动画文件）；容器原文件、Lua、`.ko` 和应用图标不会安装或执行。协议使用现有经过验证的 10 Pro / 3.101.043 VFS 与 CCN1 载波，不新增固件地址或 NSH 依赖。

## 双端确认与名称

Android 显示 `是否安装投递包：<名称>`；手环显示 `是否允许Android端安装投递包：<名称>`，熄屏时亮屏并震动。名称从投递 Lua 的单个字面量 `FONT_NAME` 或 `PACK_NAME` 读取，沿用制作台 12 字节短名，原样写入 Chaos 128 字节定长清单；不是文件名或表盘显示名。脚本不会执行。

手环：ChaosConnect → 权限设置 → Android端权限 → **安装资源包**。开启／关闭／询问，默认询问，每包确认，60 秒超时拒绝。独立配置为 `/data/chaos/connect-install.cfg`（`CCI1` + 策略字节），不复用文件写入、开发者模式或 NSH 权限。旧配置无需迁移。普通文件协议不可改写此策略；Android 不可绕过安装通道直接写字体／图标目录。

## 线格式

所有整数小端，`str` 为 u16 字节长度 + UTF-8。HELLO 新增能力位 `0x20`，旧 GET_ACCESS 结构和客户端 mask 保持不变。仅实际 Android 载波可以调用，且须先通过本次连接授权。

| opcode | 请求 |
| --- | --- |
| 0x60 BEGIN | kind:u8（1字体/2图标）、名称长度:u8、名称、文件数:u16、资源总字节:u32、整体CRC32:u32 |
| 0x61 STATUS | token:u32 |
| 0x62 OPEN_FILE | token:u32、文件名:str、长度:u32、文件CRC32:u32 |
| 0x63 WRITE | token:u32、该文件偏移:u32、数据（不超过协商chunk） |
| 0x64 END_FILE | token:u32 |
| 0x65 COMMIT | token:u32 |
| 0x66 ABORT | token:u32 |

成功应答为 token:u32、state:u8、已校验字节:u32、总字节:u32。state：0空闲、1等待确认、2允许、3拒绝、4确认超时、5传输中、6完成、7失败。错误沿用 CCN1 status。整体 CRC 覆盖 BEGIN 中 CRC 前的字段，随后依次覆盖各文件描述（不含token）和内容。

## 资源完整性与提交

- Android 严格校验 10 Pro 容器魔数、设备码、主题表、连续记录／文件区、固定四槽和 CIPK，拒绝尾部垃圾、非法路径、重复图标名、坏长度及不明确名称。SFNT 字体表须在文件边界内。
- 私有缓存文件上限 48MiB，资源总量上限 32MiB；最多 256 个图标文件。数据从缓存范围流式读取，最多协商窗口（8）个在途数据块，进度约 200ms 刷新。
- 手环再次校验名称、固定文件名／扩展名、大小、偏移、逐文件和整体 CRC，检查字体表／图像头；路径完全由模块生成。字体写入新的 `stN.ttf`，图标写入新的 `NN/` 槽，不覆盖已安装或正在使用的文件。
- 所有资源先写私有暂存目录并同步，再移动到空闲槽，最后原子重命名 `index.txt` 作为发布点。提交前复核原清单，若用户在本地修改了清单则拒绝提交。
- 拒绝、取消、断连、停用服务、撤销安装权限或校验失败均清理未提交资源。停止提交新帧后让已发送的小窗口结束，避免截断 socket 记录；不自动重发不确定的提交。
- 同名包、8 个槽已满、损坏清单或已有未登记文件占用目标槽时拒绝安装。先在 Chaos 中删除旧包，再安装替代包。安装完成后在 Chaos 字体／图标列表中选择，不自动切换正在使用的资源。

## 验证

`tools/test_connect_packages.py`：8 项生产 C / POSIX VFS 回归，覆盖字体／图标、默认询问、拒绝与超时、短写、CRC、路径、撤权、旧token、同名和并发清单变更。`tools/test_chaos_connect.py`：31 项既有回归，新增安装策略持久化和完整提示文本的宿主检查。Android 的生产 Kotlin/C 互通使用网页版实际生成的合成测试包，验证仅有读取权限也可在独立安装授权后安装、用户允许／拒绝／取消，以及安装字节和清单一致。

这些是主机协议与界面验证，不代表已在实体手环上实际安装或测量无线速度。
