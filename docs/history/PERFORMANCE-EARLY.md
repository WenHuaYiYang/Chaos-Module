# 模糊与蓝牙性能优化

目标固件：10 Pro / 3.101.043。本轮安装包以 `50c9794` 为基线叠加本轮性能补丁构建；其他任务尚未提交的功能修改保留在主工作区，不混入该构建。

## 模糊

- 全屏 BGR888 双线性放大改为先缓存水平插值，再做垂直插值。仍在最终一步舍入，随机彩色图、边缘和带 padding 的 stride 与原公式逐字节一致。中间行共 4,032 字节，使用受模糊 owner 串行保护的静态存储，不增加原生 UI 任务栈负担。
- 采样仍按配置间隔运行。新增 30,240 字节的上一帧原始缩略图；仅当采样像素、参数版本和已成功发布的 V2 输出均一致时，跳过滤波、全屏插值及新纹理分配/发布。失败、过期、参数修改、来源删除和算法切换不能启用缓存。
- 按钮仍走固件 GPU 的图像/缩放路径，CPU 负责带圆角 alpha 的材料纹理。相邻位置映射到相同半分辨率纹素时，不再复制、等待 GPU 或清缓存。负坐标保持原先的截断规则。
- 仅几何变化的 START 更新不再额外 invalidate；官方几何更新已有脏区。来源更新及 owner-poll 更新仍正常 invalidate。GPU fence、资源代数检查、退休及所有权检查全部保留。
- atlas 横坐标映射按列预计算，透明角落不再重复做无效的 RGB 乘法。

## 蓝牙

- 配对页以文本和控件代数缓存行内容；未变化时不调用 row_update，避免反复布局和重启滚动文字，熄屏不刷新。页面重建使缓存失效。
- GAP 回调仍立即更新配对状态；绑定查询 IPC 兜底从每 100 ms 一次改为每 500 ms 一次，连接确认、可发现窗口及重试期限保持原行为。
- SPP 流按连续 header/payload 分块复制，保留任意碎片、粘包、长度校验、背压和会话代数规则。
- 私有协议 owner 每次最多处理两条请求，队列未空时保持 2 ms 调度。空闲轮询从 10 ms 调整到 20 ms；不缩小协议窗口/分块大小，也不在蓝牙回调中做 VFS。
- 会屏蔽中断的旧载波连接链表扫描从每轮执行改为最多每 250 ms 一次；开关代数变化仍立即扫描，关闭的协议门禁仍立即生效。新载波连接发现最多增加 250 ms 等待。
- 修正 PAN 本地蓝牙名称 `char[32]` 的下标 32 越界写入，最多写 31 字节再在数组内补 NUL。

## 验证与限制

- `tools/test_performance.py`：生产采样/插值逐字节比较，发布缓存的失败、变化与参数失效，以及生产 Rust 文本缓存。
- `tools/test_cc_buttons.py`：资源生命周期、实际 GPU draw 参数、配置和滑动更新；120 次单像素移动的模型测试中 GPU fence/flush 从 120 次降为 60 次，几何帧没有额外 invalidate。
- `tools/test_corona_blur.py`：完整生命周期、根/屏幕变化、失败发布/唤醒、清理，以及相同帧重用前仍验证身份。
- `tools/test_blur_v2.py`、`tools/test_chaos_connect.py`：原过滤、选择及 25 项协议/权限/载波回归。
- `tools/probe_chaos_connect.py`、`tools/probe_btpan_abi.py`：真实 ARM 生产路径和 .043 固件接口探针；请求队列分批处理、开关门禁、重连、发送重试与第三方钩子保护保持通过。
- `tools/build.py --firmware 10p-3.101.043`、`verify_chaos_ko.py`：完整安装包与 ELF 校验。

主机含 ASan/UBSan 的插值微基准约为原标量公式的 1.8～2.4 倍速度，受主机负载影响。这不是手环帧率、无线吞吐或功耗的证明；真机流畅度仍需实测。周期采样仍需要安全的 GPU 截图和等待，未绕过缓存同步，也未用降低分辨率/模糊刷新频率替代实时渲染。
