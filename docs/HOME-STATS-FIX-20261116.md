# 首页 CPU / 内存 / 存储空白修复

针对上一份 `chaos-installer-10p-3.101.043-perf-20261116.bin` 的回归修复。
仅适用于小米手环 10 Pro / p67，固件 3.101.043。

上一轮将首页 `needs_tick` 增加了 APP_FG 门控，但 on_pause 会清零该标志，
on_resume 复用页面时未恢复。缓存初始为空时，首次采样被阻止，三项统计就一直空白。

修复：

- on_resume 在确认页号有效后恢复 APP_FG。
- 首页刷新依赖亮屏、时间和存活页派发，不再额外依赖可能滞后的 APP_FG。
- 保留每秒更新和已有模糊性能优化。

新增 `tools/test_home_stats.py`，提取生产首页 needs_tick/tick 和 on_resume
函数体，在宿主 UI/procfs 替身上测试首次填充、标志滞后、每秒更新、退出重进、
息屏恢复、分钟计数回绕。对上一份源码包运行时失败，能复现本次回归；修复后通过。
同时通过性能/像素测试和 Corona 模糊回归。安装包完整重编，另附源码及 SHA-256。

测试未连接手环，实际显示效果仍需设备复测。请安装文件名带 `homefix` 的新包，
不要继续使用上一份 `perf-20261116` 包。
