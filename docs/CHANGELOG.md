# 更新日志

版本号与容器头、关于页、`Cargo.toml` 三处同步；格式见 [BUILD.md](BUILD.md#版本号规则)。

## v1.0.6 — 2026-10-31

- 通用英文数字键盘新增空格键，自定义设备名称、手环型号和手环系统文本支持保存空格。
- 更换字体页面新增置顶“官方字体”选项，可恢复系统默认字体。
- 关于页、Cargo 包版本与安装容器头统一为 v1.0.6。

## v1.0.3 — 2026-10-23

重启频率最高的一版：主页圆环全部改用固件 `lv_arc`，应用管理与日志页补齐，文档重构。

### 新增

- **运行日志页**：关键操作带时间戳写入 `/data/chaos/chaos.log`，支持分页查看与两步确认清空。
- **隐藏调试页**：关于页版本号连点 5 次进入；带 LVGL 对象内存 dump（512 KB）、圆环字段对比矩阵、构造参数记录。
- **安装器重启按钮**：安装完成后可直接重启，3 秒倒计时。
- **图标投递包**（`installer/icon_pack.lua`）与**字体投递包**（`installer/font_pack.lua`）：桌面图标包与字体改为独立侧载。
- **主页双圆环**：存储与内存合并为一行显示。

### 变更

- **主页圆环改走固件 `lv_arc`**：底环 + 进度双层结构，进度用 INDICATOR 角，关掉 KNOB 圆点；
  删除会 HardFault 的样式派发器调用。
- **应用管理**：深度隐藏改为全局开关；排除项不参与批量与开机补偿；注册表缓冲扩到 32 KB；
  旧配置自动迁移并收敛重复名单；操作后不跳回列表顶部。
- **关于页**：版本行改为可连点；开发者行改为姓名主文案 + 角色小字；关于入口移到主页末行。
- **文档重构**：README 精简为概览 + 快速开始，细节拆到 `docs/`（安装、使用、构建、架构、更新日志）。
- **更新列表**：新增 [CHANGELOG-DEV.md](CHANGELOG-DEV.md)（开发者）与 [CHANGELOG-USER.md](CHANGELOG-USER.md)（使用者），给出与基线版本的逐项差异。

### 修复

- 圆环满填充、圆点乱跑、起点不在正下方等角度/字段错位问题（`MAIN` 与 `INDICATOR` 的偏移、f32/int 反复）。
- 日志页只显示 5 行、行数组越界导致界面卡死、滚动翻不到底。
- 排除项残留隐藏状态、显示后出现重复图标、隐藏/显示状态错乱。
- 安装器重启按钮与标题重叠、倒计时跳秒。
- 圆环触摸拖拽误改百分比（已关闭拖拽）。

### 已知限制

- 仍只支持固件 **3.101.043**；无固件指纹校验。
- 不提供一键卸载（模块不做 `rmmod`，见 [INSTALL.md](INSTALL.md#卸载与回退)）。
