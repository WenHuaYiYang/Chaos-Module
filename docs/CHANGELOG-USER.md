# 更新列表（v1.1.3）

- 应用管理页、批量操作页操作后不再整页重建：只更新变化的那几行，列表滚动位置保持不动。
- 连续点选/快速切换时不再卡顿，也不会因为整页重建而跳回列表顶部。
- 版本号显示 v1.1.3。

# 更新列表（v1.1.2）

- 界面更紧凑：顶部按钮改为并排摆放（一行两个），状态和信息行压低了高度，一屏能多显示应用。
- 应用详情页的“隐藏/显示”和“卸载应用”并排一行；批量操作页的四个按钮也改为并排，腾出更多列表空间。
- 返回统一用标题栏返回键，页面里不再单独占一行“返回”。
- 版本号显示 v1.1.2。

# 更新列表（v1.1.1）

- 修复重装后桌面出现两个 Chaos 图标的问题：重装更新桌面入口时先清掉旧图标再添加。
- 版本号显示 v1.1.1。

# 更新列表（v1.1.0）

- 应用管理页重构：每行显示应用名 + 彩色状态（已隐藏/显示中），点应用进入详情页。
- 新增应用详情页：显示包名、占用大小、版本，可切换隐藏/显示，可卸载（二次确认）。
- 新增批量操作页：全选/取消全选，对选中的应用批量隐藏、显示或删除（删除需二次确认）。
- 隐藏方式统一为深度隐藏，不再区分普通/深度；旧的普通隐藏记录在首次运行后自动迁移。
- 卸载改为文件级删除（六个目录 + 注册表条目 + 桌面图标），立即生效，重启后不再出现。
- 排除项页目前仍是勾选式管理。
- 版本号显示 v1.1.0。

# 更新列表（v1.0.7）

- 新增“系统关于页面修改”：系统版本显示、手环系统文本、设备名称、手环型号都能改，自定义值用通用键盘输入。
- 新增“恢复 fetch 支持”说明页，fetch 模块与证书随安装器一起部署。
- 新增开放源代码许可页。
- 安装器新增“应用列表显示”开关。
- 系统美化新增“应用列表设置”：桌面缩放、排距、内缩三个开关，选择会记住，重启后自动应用。
- 修复关于页“开放源代码许可”点不动的问题。
- 版本号显示 v1.0.7。

- 通用键盘新增“SPACE”空格键。
- 自定义设备名称、手环型号和手环系统文本支持空格。
- “更换字体”页面顶部新增“官方字体”，选择后退出 Chaos 即可恢复。
- 应用管理页新增“重新应用隐藏”；换绑新手机或手机重发应用清单后，隐藏状态会自动补回。
- 版本号显示 v1.0.6。

## 排除项

勾上的应用，批量隐藏/显示时不会被一起改掉，重启后也不会被自动隐藏。勾完立刻生效。

## 深度隐藏

- **开**：隐藏的应用重启后彻底消失；想恢复要先关掉开关再重启。
- **关**：隐藏/显示点了立刻生效。

切换开关后要重启一次。
