# 更新列表（v1.0.3）

- 主页新增“关于”入口（原来在设置页底部）。
- 设置页改成“运行日志”入口，新增日志页：可翻页、刷新、清空。
- 应用管理页新增“排除项管理”入口和“深度隐藏”开关。
- 安装器新增“重启”按钮（3 秒倒计时）。
- 版本号 v1.0.3，安装包重新打包。

其余（进度条、表盘、字体、图标、美化）无变化。

## 排除项

勾上的应用不参与“一键隐藏/显示”，也不会被开机自动隐藏；名单存在 `/data/chaos/appmgr_excl.bin`，立即生效，最多 40 个。

## 深度隐藏

- **关**：只写隐藏标记，隐藏/显示立即生效，条目仍在系统里。
- **开**：把条目搬到 `apps.json_hide`，重启后彻底不出现。

注意：开关是全局的，切换后**要重启**；会改系统应用列表，别在低电量时批量操作。
