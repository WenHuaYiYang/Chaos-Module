# 更新列表（用户）

对比上一个公开版本（v1.0.2 / 10-18 版）到 **v1.0.3**。

## 变化

- **主页圆环**：存储、内存从横条改成双色圆环，百分比显示在中间。
- **运行日志**：新增“运行日志”页，能看到最近的操作记录（批量、排除项、模式切换），可翻页、可清空。
- **应用管理**：新增“排除项”页和“深度隐藏”开关，见下面两节。
- **安装器**：装完后可以直接点“重启”，3 秒倒计时。
- **隐藏调试入口**：关于页的版本号连点 5 次，进入调试页（普通使用用不到）。
- 安装包已重新打包，版本号统一为 **v1.0.3**。

## 排除项管理

**是什么**：告诉 Chaos“这几个应用别替我管”。

勾上排除项之后：

- “一键隐藏/显示全部”不会动它
- 重启后的自动补隐藏不会动它
- 应用管理主列表里也不显示它（在“排除项”页里管理）

**什么时候用**：某个应用你想自己手动隐藏/显示，不希望 Chaos 的批量操作把它一起改掉。

**注意**：

- 排除项不是“上锁”。你手动在系统里隐藏它，Chaos 不会改回来，也不会自动帮你显示。
- 上限 40 个，和全部应用数同一个上限。
- 勾选/取消后直接生效，不用重启。

## 深度隐藏：开与关

这是应用管理页里的一个**全局开关**，决定“隐藏”到底是哪种隐藏。

**关（普通隐藏，立即生效）**

- 只改 Chaos 自己的隐藏名单，应用条目还在系统的 `apps.json` 里。
- 点“隐藏”马上从桌面消失，不用重启。
- 缺点：条目仍然存在，系统更新或别的工具可能让它重新冒出来。

**开（深度隐藏，重启后生效）**

- 把选中的应用从 `apps.json` 搬到 `apps.json_hide`，开机时系统根本不会注册它。
- 重启后图标彻底消失，最干净；想恢复必须先关掉开关，再重启。

**注意**：

- 开关是全局的，对批量操作里选中的应用一起生效；排除项里的不受影响。
- **切换开关后要重启**，看到的才是最终结果。
- 深度隐藏会改系统应用注册表文件，别在快没电时批量操作，中途断电可能导致应用列表残缺。
- 想恢复被深度隐藏的应用：关掉开关 → 重启 → 回应用管理点“显示”。
