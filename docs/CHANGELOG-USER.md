# 更新列表（用户）

从上一个公开版本（v1.0.2）到 **v1.0.3**，界面上能直接看到的变化只有下面这些。

## 变化

- **主页新增“关于”入口**：原来关于信息藏在“设置”页最下面，现在主页最后一行直接进“关于”。
- **“设置”页**：关于信息挪走后，空出的位置给了“运行日志”。
- **新增“运行日志”页**：能看到最近的操作记录，可翻页、刷新、清空。
- **应用管理页多了两行**：“排除项管理”入口和“深度隐藏”开关，见下两节。
- **新增“排除项管理”页**：从这里挑应用，告诉 Chaos 别去动它们。
- **安装器**：加了“重启”按钮（点一下 3 秒倒计时再重启），主界面按钮位置调了一下。
- **版本号变 v1.0.3**，安装包重新打过。

主页的存储/内存进度条、表盘、字体、桌面图标、美化这些都没变。

## 排除项管理

**作用**：挑几个应用出来，告诉 Chaos“这些别替我管”。

勾上之后：

- “一键隐藏全部 / 一键显示全部”不会碰它
- 重启后的自动补隐藏不会碰它
- 应用管理主列表里也不再显示它，只在“排除项管理”页里出现

**注意**：

- 排除项不是“上锁”。它只是不参与批量操作；在这个页里切到“模式: 管理显隐”，仍能单独隐藏/显示它。
- 最多 40 个。
- 改动立即生效，不用重启。
- 名单存在 `/data/chaos/appmgr_excl.bin`，不碰系统文件，删掉这个文件等于清空排除项。

## 深度隐藏：开与关

应用管理页上的一个开关，决定“隐藏”是哪种做法。

**关（普通隐藏）**

- 只把“隐藏”标记写进 `/data/apps.json`，条目还留在系统里。
- 隐藏/显示立即生效，不用重启。
- 缺点：条目还在，系统更新或别的工具可能让它重新冒出来。

**开（深度隐藏）**

- 把隐藏的应用条目从 `/data/apps.json` 搬到 `/data/apps.json_hide`，开机时系统根本不会注册它。
- 提示是“深度隐藏已开启, 重启后生效”——**要重启才看得到最终效果**。

**注意**：

- 开关是全局的：批量隐藏/显示都按当前开关执行。
- 来回切换开关会迁移已有条目，切完也要**重启**才生效。
- 迁移靠改系统应用注册表完成，别在快没电时批量操作，中途断电可能让应用列表残缺。
- 想恢复被深度隐藏的应用：关掉开关 → 重启 → 回应用管理点“显示”。
- 排除项里的应用不受这个开关影响。
