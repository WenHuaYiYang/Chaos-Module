# 更新列表（v1.1.5）

- 「系统模糊」页的「corona模糊」开关已停用（代码里注释保留）：它和「模糊v2」本来就是同一套引擎，并排摆着只会让人以为有两套算法。
- 修复开过两个应用后模糊突然失效：原生 launcher 的 owner 被摘掉后没人重新接管，模块还一直以为自己持有场景。现在有所有权看门狗，连续丢失 3 拍就重新 commit，重装带 2 秒防抖。
- 修复固件「滚动进行中」标记（RAM 0x201102D9）卡住导致模糊永久失效：只在 native 渲染/层任务全空闲时连续 60 拍后才自动清零这一字节，不打断真实手势。
- 修复「开了透明 → 切模糊 → 再触发」后换什么档位都透明：还原旧引擎台账时真正写回原值并清账，不再把“我们写进去的 0”记成原样；通知聚合页的透明补丁也纳入还原范围。
- 接管期间禁止旧引擎动同一批根节点：退出主页时的 unmount 不再和 Corona 抢所有权。
- 模糊连续 5 秒无法接管时自动降级到系统背景（状态行会写“模糊引擎已暂停，系统背景生效中”），20 秒后自动重试一次，不再无限停在“看着像坏了”。
- 「关于 → 连点 5 次 → ③ 调试信息」新增 `-- blur --` 段：接管态、区域掩码、暂停/失败计数，以及 C 侧 Corona 状态机快照（owned/owner/latch/src/pend/gate/…）。
