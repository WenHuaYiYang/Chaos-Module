# 横向 QWERTY 键盘

适用范围：小米手环 10 Pro / p67 / **3.101.043**。实现位于
`supervisor/src/keyboard.rs`，四个自定义文本入口继续使用原有 `Completion` 保存回调。
不增加页面，不改变保存格式、31 字节缓冲上限或发行版本号。

## 按键文字居中修正（2026-11-01，版本 1.0.7）

文字靠右的原因是 `align::CENTER` 被定义为 8，固件里它实际是右侧居中，
真正的水平、垂直居中为 9。已更正 `supervisor/src/fw_api/align.rs` 的常量；
原有 `obj_align(label, CENTER, 0, 0)` 调用自动覆盖全部 42 个字符与操作按键，
不需要新增样式写入、修改字体或手算偏移。输入框和键盘左右滚动配置不变。

主机测试现在复用生产代码的对齐常量，并记录对齐参数，不再忽略该参数或复制一份枚举。
新增断言已在旧值 8 下复现失败，在修正为 9 后通过；全部 8 项测试通过，
包括初次建页、切换到小写、切回大写时的对齐。固件校验脚本也核对 8/9 的布局分支。
这些检查不包含设备屏幕的实拍验收；真机显示效果仍需复测。

## 布局与交互

- 页面 content 仍为 336×424，位于屏幕 y=56；content 自身不滚动。
- 输入框位置 (8, 4)，尺寸 320×48。
- 独立键盘视口位置 (0, 56)，尺寸 336×232，只允许横向滚动。
- 视口内的键盘底板为 640×224；字符键 56×50，键间距 8，行步长 58。
- 四行分别为 `1234567890`、`qwertyuiop`、`asdfghjkl`、`zxcvbnm`，起始 x 分别为 4、4、36、100。四行共用同一底板，不独立滚动。
- 可横向移动范围为 0..304；左右两端的数字/字母都可完整进入视口，所有按键坐标非负。
- 两行操作区固定在 y=296、348，高 44，最底边为 392，保留 content 底部 32px 手势区。
- 仅监听原生 `CLICKED`，由 LVGL 区分拖动和点击。视口关闭弹性越界、滚动链和手势冒泡，标题返回键继续由固件处理。
- 大小写切换只更新 26 个字母标签和大小写键标签，不删除对象或请求重建，因此不重置滚动位置。
- `open` 和每次 `render` 都清空标签缓存；按键事件先检查前台页与对象树存活状态，避免离页后更新失效对象。

## 固件接口依据（静态核对）

镜像：`research/firmware-3.101.043/043_ABI/executables/raw_arm_thumb/vela_ap.bin`。
SHA-256：`519307675665e4866d722a8119a98589c397b614ac3294cb87bfc86de45756ec`。
以下小地址为镜像文件偏移。**仅已确认留在 flash 的 thunk** 可以按偏移
+ `0x0C0C0000` 换算，Thumb 调用另置 bit0；SRAM/PSRAM 载入副本不能套用这个规则。

| 用途 | 依据 |
|---|---|
| 按键对象居中参数 9 | `obj_align` 的 flash 壳 file `0x4C9188` -> `0x1C02A501`（镜像本体 `0x77940`），经 `0xC7938` -> `0x002BE2FD`（本体 `0x48168`）写 alignment 属性 `0xA`。布局函数 `0x79290` 读取 `0xA`，`0x79356` 减 2 后查 `0x79360` 的 TBB 表：8 -> `0x79466`，x 取完整宽度差、y 取半高差，即靠右；9 -> `0x794A2`，x/y 均按父子半尺寸差计算，即双向居中。 |
| local style 正式入口 | flash 文件 `0x00A00BB0` 的 8 字节为 `5f f8 00 f0 25 d9 2b 00`，即跳转到 `0x002BD925`。系统调用点 `0x009E65F8..0x009E6600` 把 prop 放 R1、value 放 R2，从描述符取 obj/selector 到 R0/R3，再调用此 thunk。Rust 入口为 `0x0CAC0BB1`，没有返回值。 |
| SRAM 搬运关系 | 启动 `0xB6E -> 0xA60`，表 `0xAA8/0xAAC/0xAB0` 为源 `0x2C0FC6CC`、目标 `0x200B2860`、源末端 `0x2C10D438`；文件 `0x47790` 落在目标 `0x200BD924`，对应执行地址 `0x002BD924`。五个官方属性 setter 的 thunk 与各自镜像本体均证实相同映射。 |
| PSRAM 搬运关系 | 启动 `0xB7A -> 0xAC8`，表 `0xB20/0xB24/0xB28` 为源 `0x2C10D440`、目标 `0x3C000000`、源末端 `0x2C18D940`；文件 `0x7A028` 落在目标 `0x3C02CBE8`，对应执行地址 `0x1C02CBE8`。 |
| `obj_set_scroll_dir(obj, dir)` | `0x004C84C8` 是 `ldr.w pc,[pc]` 跳转壳，槽值 `0x1C02CBE9`；新封装调用 `0x0C5884C9`。其镜像本体 `0x0007A028` 调 `0x00076240` 分配 spec_attr 后，将第二参数写到 `spec_attr+0x32` 的 bits 6..9。相邻 getter `0x0007A0C0` 读取同一字段，缺省为 0xF。 |
| 横向方向掩码 3 | 输入处理 `0x0009FFEA` 调上述 getter，随后分别检测 1、2、4、8；横向分支 `0x000A03E0` 使用 x 位移和 1/2，纵向分支使用 y 位移和 4/8。 |
| 滚动链标志 `0x100 / 0x200` | `0x000A00F2` / `0x000A0106` 分别查询这两个标志，再决定是否通过 `0x0007C538` 向父对象继续寻找滚动容器。 |
| 手势冒泡标志 `0x8000` | `0x0009E6D2` 查询此标志；非零时循环经 `0x0007C538` 上溯父对象，然后在选定对象上处理手势。 |
| 上/下/左/右内边距 `0x10..0x13` | 子对象构造 `0x000756C0` 以 0x10/0x12 计算 y/x 原点；纵向滚动范围 `0x0007A164` 取 0x10/0x11，横向范围 `0x00079D7C` 取 0x12/0x13。 |
| 边框宽度 `0x30` | 上述两个滚动范围函数同时取 0x30，并按 0x34 的边框方向位加入对应边界。通过修正后的正式 local style 入口将边距及边框宽度设为 0，不移除主题字体、颜色或圆角。 |
| 官方清边距调用链 | 本体 `0x48258/0x48270/0x48288/0x482A0/0x484A0` 分别把属性 `0x10/0x11/0x12/0x13/0x30` 放 R1，value 放 R2、selector 放 R3，BL 到文件本体 `0x47790`。官方 thunk 分别为文件 `0x4C80A0/0x4C93C0/0x4C89C0/0x4C7C60/0x4C8770`。系统建对象 `0x408492` 后在 `0x4084AA..0x4084EC` 用 `(obj, 0, 0)` 清这些属性。 |

`0x0007A028` 的 32 字节签名：

```text
b0 b5 05 46 0c 46 00 af fc f7 06 f9 aa 68 53 8e
c3 f3 83 11 a1 42 1c bf 64 f3 89 13 53 86 b0 bd
```

可用 `xxd -s 0x4c84c8 -l 8 <镜像>` 核对跳转壳，
`xxd -s 0x7a028 -l 32 <镜像>` 核对签名。反汇编使用 Thumb v8-M 模式；
不能直接把另一型号/版本的地址或 LVGL 结构体偏移移植过来。

## 验证

首先直接核对本地固件镜像（缺镜像或版本不一致时失败，不跳过）：

```sh
python3 tools/verify_keyboard_abi.py
```

校验范围：镜像 SHA-256、启动搬运表、函数签名、正式 thunk 目标、系统实际调用点、
五个官方属性 setter 的参数转发、Rust 封装使用的地址和无返回值声明，
以及对象对齐入口、布局分派表与 8/9 分支的几何运算。
这仍是静态检查，不执行设备代码，不模拟内存保护、堆或 UI 线程。

主机回归测试直接编译实际 `keyboard.rs`，仅将固件 UI 和四个保存回调替换为记录型 mock：

```sh
sh tools/test_keyboard.sh
```

当前源码通过 `python3 tools/build.py --skip-fetch --no-icons` 重建 1.0.7 安装器；
构建通过不等于真机验收，不将旧包或新包的主机测试结果视为设备验证通过。

覆盖完整键位顺序、错位与间距、两端可达、横向滚动配置、操作区范围与无重叠、大小写原位更新、
输入/空格/数字/小数点/退格/清空/长度边界、非点击事件、离页保护、四种保存路由、保存失败及重入。
mock 的滚动位置断言只验证切换大小写不重建对象；它不是触摸驱动或 LVGL 渲染仿真。

真机验收仍需在上述固件执行：

1. 分别从系统版本、手环系统文本、设备名称、手环型号进入编辑页，检查默认值与标题。
2. 从按键中心和键间空隙向左拖至最右端，再向右拖回，确认四行同步、P/0/L/M 和 Q/1/A/Z 可输入，拖动松手不额外输入字符。
3. 在两个边界继续向外拖、在键盘区上下/斜向拖动，确认不导致返回、纵向位移或操作区错位。
4. 在右半部分连续切换大小写，确认不跳回左端、已输入内容保留；再测试 SPACE、退格、CLR 和小数点。
5. 输入 31 字节后再输入，确认不会越界；分别测试空输入确认、正常保存、取消编辑后重进。
6. 更换较大系统字体后检查字符及 ABC/SPACE/CLR/OK 不被裁切；息屏唤醒和反复进出后检查没有失效标签访问。
