# 当前性能说明

适用范围：本 fork 当前源码，小米手环 10 Pro / p67 / 固件 **3.101.043**。本页汇总已经实施的优化及其代价；初始审查、阶段测试数字和原始方案见 [历史记录](history/README.md)。

## 已实施的改动

| 范围 | 当前行为 | 影响与取舍 |
|---|---|---|
| 首页统计与维护 | CPU、内存、存储按约 1 秒更新；恢复前台时重新允许更新，周期使用时间判断 | 数值不是逐帧刷新；已修复统计空白回归 |
| 开机应用管理补偿 | 重试按 2/4/10 秒退避，总时长上限 5 分钟，等待时不单独维持全局快拍 | 失败时稍后重试，避免持续高频轮询 |
| 隐藏兜底与字体 | 隐藏检查亮屏约 800ms、息屏约 160s；息屏跳过字体热扫描 | 兜底发现有延迟；字体尚未改成完整增量扫描 |
| 应用详情目录统计 | 每次最多推进 24 个遍历步骤，使用 2ms 软预算；关闭时释放句柄 | 总大小逐步完成；单次文件系统调用仍可能超过软预算 |
| 模糊像素计算 | 合并 BGR888/RGB565 缩采样与颜色处理，批次复用查表，保持各格式原舍入规则 | 以约 1.5KiB 静态查表换取重复计算减少 |
| 静止背景复用 | 原有缩略图比较与参数身份检查保留，相同输入跳过滤波与发布 | 仍需安全采样；不是完全取消 GPU 截图 |
| 桌面与控制中心滑动 | 交互期间复用已发布背景，暂停新 COPY、滤波和发布；停止约 160ms 后恢复 | 滑动期间模糊内容暂时停留在上一帧，首次模糊可能在停止后出现 |
| 控制中心按钮 | 移动期间保留纹理与几何更新，停止后更新取样 | 玻璃纹理暂随按钮移动，停止后重新对齐；删除与复用仍保留 GPU 同步 |
| S541 控制条 | 立即显示按钮，位置稳定约 160ms 后从已发布 V2 背景生成可选玻璃；不再读 framebuffer 或失效整屏附加层 | 无背景缓存时只显示按钮，最多每 500ms 查询一次；关闭模糊时不额外截图生成玻璃 |
| 蓝牙与文件桥 | 保留文本缓存、分块复制、有界队列处理及低频兜底 | 低频发现存在等待，详见 [早期实现记录](history/PERFORMANCE-EARLY.md) |
| 构建 | network C 对象按内容、命令及工具身份缓存，构建输出步骤耗时 | 暖构建更快；首次编译和工具链变化仍需重新编译 |

S541 仍受现有维护节拍影响，不能据此宣称达到 60fps。模糊变更没有绕过资源所有权、退休检查、GPU fence 或缓存同步。

## 相关功能修复

- 快应用动画只在桌面且亮屏时接管延迟启动；从 Chaos 应用管理打开快应用走原启动链，避免下一拍取消启动。见 [快应用动画](QUICKAPP-ANIMATION.md)。
- 首页统计恢复逻辑已补回归测试，见 [修复记录](HOME-STATS-FIX-20261116.md)。
- S541 的素材压缩减少安装文件体积；解压后的像素缓冲仍占内存，不能将安装包缩小量当作 RAM 节省。

## 已验证与尚未验证

主机测试覆盖像素一致性、查表与缓存失效、时间回绕、统计恢复、滑动事件、模糊生命周期和 S541 缓存采样；构建已在 Windows 工具链完成。运行方法见 [测试指南](TESTING.md)。

阶段记录中的 network 冷构建约 7.93 秒、暖构建约 0.64 秒，以及复用图标与 fetch 组件后的安装包构建约 21.38 秒，只代表当时机器和缓存条件。微基准倍数也只针对受测计算，不能换算为整机提速比例。

尚无本轮真机帧时间、功耗或长期低内存测量，不能承诺所有页面明显加速。桌面和控制中心同时开启模糊仍可能受到固件渲染、GPU 截图、纹理带宽与其它动画影响。

## 后续优化与验收

1. 固定表盘、亮度、应用数量及蓝牙状态，比较未加载 Chaos、关闭效果、仅桌面模糊、仅控制中心模糊、两者全开与 S541 开关组合。
2. 在 RAM 中聚合维护回调耗时、长帧比例、截图/发布次数和最大连续空闲内存，按需导出；避免逐帧写闪存。
3. 根据真机热点决定是否细分剩余扫描任务、调整采样频率或提供画质档位。降低画质或更新频率属于体验取舍，需要单独说明。
4. 使用相同条件的长时间对照测试续航，检查快速滑动、反复开关、息屏唤醒、页面删除及低内存恢复。

这些是待实施或待验收事项；[初始性能计划](PERFORMANCE-PLAN.md) 中的百分比和耗时目标不是已达成结果。
