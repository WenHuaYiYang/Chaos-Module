# 屏幕设置的保存与注入恢复

- **屏幕翻转**仅本次运行有效，不读写旧的 `screen-rotation.cfg`，重新注入默认正常方向。
- **自动熄屏秒数**使用纯数字键盘，范围 1～2147483 秒。保存到模块自己的
  `/data/chaos/dimmer-timeout.cfg`（DIM1、秒数、校验），每次注入后写回系统内存的毫秒字段。
  缺失或损坏的配置保留当前系统值，不把临时常亮值自动保存为模块偏好。
- **关闭遮盖熄屏**默认关闭，沿用 `/data/chaos/disable-touch-palm.cfg` 的一字节配置。
  开关开启时系统 `touch_palm=0`，关闭时为 1；每次注入都自动应用保存的值。

恢复入口在 `watchface::tick_app` 的开机延迟结束后、UI owner 上执行，无需打开 Chaos。
SIM_LITE 保持原有的原生服务隔离。熄屏时间与遮盖设置每次注入只恢复一次，
不周期性覆盖系统设置，不周期性写配置；灵动点的临时常亮借用与释放逻辑仍独立运行。
配置写入处理短 I/O、有限次数 EINTR、关闭错误，并验证临时文件后原子重命名。
失败时保留旧文件：熄屏秒数不应用失败的新值并显示保存失败；遮盖开关本次运行生效并提示未保存。

精确核对 10 Pro / 3.101.043 AP：
SHA-256 `519307675665e4866d722a8119a98589c397b614ac3294cb87bfc86de45756ec`。
屏幕服务结构地址为 `0x2013f368`，原生 timeout setter `0x0ca72288`
在 `0x0ca722aa` 写 `+0xd4`，随后调用 `0x0ca70360`；palm setter
`0x0ca7290c` 在 `0x0ca72926` 写 `+0xd2`，随后调用 `0x0ca714b4`。
模块只通过已核对的 RAM 字段与刷新函数应用设置，不调用会写系统 persist 属性的原生 setter。

验证：`tools/test_screen_settings.py` 编译实际设置与文件存储模块，覆盖注入恢复、
旧遮盖配置、旧翻转配置忽略、延迟显示、常亮不干扰、输入边界、损坏/超长配置、短 I/O、
EINTR、写入/关闭/重命名失败。`tools/verify_screen_settings_abi.py` 校验精确固件和生产绑定。
上述为主机与固件静态证据，真机行为仍需安装后验证。
