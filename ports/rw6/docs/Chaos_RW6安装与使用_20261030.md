# Chaos on Redmi Watch 6（RW6 / p65）安装与使用

面向拿到这台包的人：这是什么、怎么装上、装完是什么样、哪些是验过的、哪些还没有。

## 1. 这是什么

RW6（Redmi Watch 6）跑的是 NuttX + Vela，**没有** 10 Pro 那套"表盘容器安装器"。
RW6 上的 Chaos 是一个 **NuttX 内核模块**（modlib 格式的 `.ko`）：
装载后向固件的 app 框架注册一个叫 `Chaos` 的应用，自己带六个页面。

模块与固件版本**绑定**：换固件版本要重新出包（里面的固件入口地址是按这一版固件定的）。

## 2. 交付物

`dist/chaos-p65-043-v1.tar`（约 80KB），包内：

| 文件 | 作用 |
|---|---|
| `chaos_sup_p65.ko` | Chaos 主程序（内核模块，ELF 头 e_entry 已补成 module_main） |
| `chaos_icon.bin` | 桌面图标 |
| `install.sh` | 安装（insmod + lsmod 自检） |
| `uninstall.sh` | 卸载（rmmod） |
| `README.txt` | 包内简版说明 |

## 3. 安装（手表 NSH 里执行）

先把 `chaos-p65-043-v1.tar` 传到手表的 `/data`，然后：

```
tar -C /data -x /data/chaos-p65-043-v1.tar
sh /data/install.sh
```

`install.sh` 会 insmod 并打印 `lsmod`；看到一行 `chaos_p65` 就是装上了。
桌面会出现 Chaos 图标，点开即用。

**卸载**：

```
sh /data/uninstall.sh
```

**两个设备侧的限制**（实测过，不是猜的）：

- NuttX 的 `tar` 只吃 USTAR 格式，PAX 会报 `tar_extract_all(): Unknown error 22`；
- 设备上的 `tar` 不支持 `-z`，所以给的是 `.tar` 而不是 `.tar.gz`。

需要时再从代码里接回来。

二、**没做的**（明确列出来，别以为装上就有）：

- **开机不自动加载**：RW6 的 `/etc/init.d` 在只读 romfs 里，固件也没有任何地方
  从 `/data` 执行脚本或 insmod ⇒ **每次重启后要手动再跑一次 `sh /data/install.sh`**。
- 与 10P 逐页对照后，以下几条在 RW6 上被平台卡住（不是没写，是写不了/没验成）：
  - **时间·日期设置**：没找到时钟入口（`/proc` 无时间源、`/dev/rtc0` 无字符串引用、
    libc 的 clock_* 不导出给模块）。
  - **更换字体**：RW6 字体在只读的 `/resource/font`，改不了。
  - **系统模糊 / 模糊区域**：RW6 的 LVGL 里没有 blur 属性。
  - **表盘管理（删除）**：删除 API 返回 0 但文件不动，且 builtin 删除不可逆。
  - **摇一摇轮换**：镜像里没有摇晃事件源。
- 模拟器里 launcher 桌面能出网格（crown 切），但**桌面图标的最终观感仍以真机为准**。

## 5. 升级

覆盖安装即可（先 rmmod 再装新的）：

```
rmmod chaos_p65
tar -C /data -x /data/chaos-p65-043-v1.tar
sh /data/install.sh
```

## 6. 出包与自检

```bash
python scripts/build_chaos_p65_installer.py   # -> dist/chaos-p65-043-v1.tar
```

找锚点 → 在 guest 里做执行级验证 → 落地 → 逐页截图回归 → 出包。
